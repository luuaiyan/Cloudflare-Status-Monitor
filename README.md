## ✨ 核心功能特性

本面板专为轻量化、高安全性和极佳的视觉体验而设计，摒弃了传统繁琐的探针脚本，将监控逻辑全部交由 Cloudflare 边缘节点处理。

### 📡 1. 智能监控 (Agentless)
* **🛡️ 零探针 TCP 服务监控**：告别繁琐的 Bash 脚本！直接利用 Worker 底层 TCP Socket 探测服务器的 Host:Port（如 SSH的22端口、数据库的3306端口等）。完全免安装，**不占用服务器任何内部资源**。
* **🌐 高级 API / 网站监控**：不仅支持常规网页存活检测，还支持高度定制化的 API 接口健康度检查。允许自定义请求方法 (`GET` / `POST` / `PUT` / `HEAD`)，支持携带自定义 `Headers` (JSON格式) 和请求 `Body`。

### 🎨 2. 现代化 UI/UX
* **📊 ECharts 图表**：完美对齐的 24 小时动态响应柱状图。固定 24 根时间柱，根据真实的 Ping 延迟自适应柱子高度。智能颜色标记（🟢 正常 / 🟠 超时 / 🔴 宕机），支持鼠标悬停丝滑显示具体数值。
* **🍎 Apple 级毛玻璃质感**：全站采用 `Glassmorphism` 高斯模糊与渐变色彩设计。
* **🌓 智能明暗主题自适应**：内置本地时钟检测，早 6 点至晚 18 点自动使用亮色 (Light) 主题，夜间自动切换为暗色 (Dark) 主题，同时支持手动一键切换。
* **📱 完美的多端适配**：桌面端采用强制定宽百分比表格，实现多表像素级垂直对齐；移动端自动转换为精致的数据卡片布局。

### ⚙️ 3. 极简的后台交互
* **🖱️ 原生拖拽排序 (Drag & Drop)**：后台管理支持原生 HTML5 拖拽，按住列表最左侧的 `⋮⋮` 把手即可自由排序，全自动静默保存，无需刷新。
* **🧹 智能数据维护 (Data Maintenance)**：自带 D1 数据库空间优化模块。一键清理 24 小时前的冗余日志，或一键彻底重置（Purge）所有状态与历史，确保面板永远极速运行且不超配额。
* **🔔 Bark 实时预警推送**：内置 Bark 消息通知。服务下线或重新上线时，瞬间秒推手机通知。后台提供 `Test Push` 一键测试配置连通性。

## 🔐 安全架构

针对前后端分离架构和公网暴露的痛点，本项目构建了 5 道核心安全防线：

1.  **物理级数据脱敏 (Data Masking)**：公开 API 接口在返回数据前，会从底层彻底剔除 `Host`, `Port`, `URL`, `Headers`, `Body` 等敏感字段。访客即便通过抓包，也无法获取你家宽带的真实 IP 或 NAS 内部入口。
2.  **幽灵登录入口 (Secret Route)**：支持通过 Cloudflare 环境变量 `LOGIN` 自定义私密登录后缀（例如设置 `LOGIN=my-secret-admin`，则只能通过 `/my-secret-admin` 访问）。原默认的 `/login.html` 将返回 404，让恶意扫描机器人无门可入。
3.  **防爆破登录锁 (Brute-force Protection)**：内置 IP 拦截器。连续输错 5 次密码，该账号/IP 将被强制锁定 15 分钟。
4.  **单向哈希加密 (PBKDF2 Hash)**：密码在数据库中采用加盐（Salt）及 1000 次 SHA-256 迭代哈希加密存储。即使 D1 数据库被拖库，也无法反推明文密码。
5.  **JWT 身份校验与持久化**：使用安全的无状态令牌 (JSON Web Token) 进行鉴权，Token 有效期长达 30 天，支持浏览器密码自动填充记忆；点击退出即刻吊销 (Revoke) 令牌。

## 🛠️ 快速部署指南

本面板支持**傻瓜式零步部署**，无需手动调用任何 API 初始化数据库！内置防呆引导机制，绑定完 D1 数据库后首次访问即可瞬间自动建表。

### 第一步：创建 D1 数据库
进入 Cloudflare Dashboard -> **存储和数据库** -> **D1 SQL 数据库** -> 点击 **创建数据库**（名称任意）。

### 第二步：创建 Worker 并绑定数据库
1.  在 Cloudflare 中创建一个新的 Worker，从HelloWorld模版开始，将本项目 `worker.js` 的代码完整复制粘贴并部署。
2.  进入该 Worker 的 **设置 (Settings)** -> **绑定 (Bindings)**。
3.  添加一个 D1 数据库绑定：
    * **变量名称** 必须严格填写为：`DB` (全大写)
    * **D1 数据库** 选择你刚刚创建的数据库。

### 第三步：配置环境变量 (必须！！！)
在 Worker 的 **设置** -> **变量和机密** 中，你可以配置以下参数增强安全性（建议配置）：
* `USERNAME`: 自定义后台账号
* `PASSWORD`: 自定义后台密码
* `LOGIN`（可选）: 默认为`https://你的域名/login.html` ，自定义私密登录后缀（例如填写 `admin-panel`，则后台地址变为 `https://你的域名/admin-panel`）

### 第四步： 设置定时
在 Worker 的 **设置** -> **触发事件** 中，添加一个 **Cron 触发器**，一般建议30分钟或者1h触发一次。

> 其实我已经写了自定义每个检测项目的检测时间代码，主要是针对重点项目检测频率增加，偶尔使用的项目降低检测频率。
> 但是这个功能对我自己来说不是很实用，也不是很想发布，没有什么是必须立刻知道情况然后立刻需要解决的。
> 让生活节奏慢一点，让头发少掉一点，让自己多睡一会儿，让我们多享受一点。

### 第四步：完成部署！
1. 直接访问你的 Worker 域名。系统会自动检测并静默初始化所有数据库表。
2. 访问你的专属登录链接，即可开始添加你需要监控的服务器与网站！

## 💡 常见问题 (FAQ)

**Q: 为什么我访问页面提示 "Action Required: D1 Database is not bound"？**
A: 这是本项目的防呆引导机制。说明程序未能检测到绑定的数据库。请严格按照部署指南的第二步，检查绑定的变量名是否为纯大写的 `DB`。

**Q: 为什么首页公开面板上，我添加的服务显示为 "未命名服务"？**
A: 这是为了保护你的隐私。由于底层安全清洗机制删除了 IP 和 URL，如果你在后台添加监控时**没有填写“名称(Name)”**，前端将无法显示真实的 URL，只能显示缺省文本。**强烈建议为家庭 NAS 等敏感服务填写安全的代号名称**（如：`Home Router`, `Plex Media` 等）。
